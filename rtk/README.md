## Install

### Windows
- Add the current directory to the Windows PATH.

### Linux/WSL
```bash
curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh

rtk init -g

rtk --version

rtk init --show
```
